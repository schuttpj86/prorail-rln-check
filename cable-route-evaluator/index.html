Welcome to ProRail Cable Route Evaluator

In the Netherlands, ProRail Standard RLN00398 (Version 004, 01-06-2025) is used for the evaluation of electromagnetic interference between high-voltage connections and railway infrastructure.

This standard includes a flow diagram (Figure 1) for assessing compliance. The tool performs automated checks following this flowchart to determine whether more detailed electromagnetic compatibility (EMC) studies are required.

This tool focuses on the preliminary evaluation phase—not detailed studies—enabling fast assessment and comparative analysis of different cable and overhead line routes.

Key Capabilities:

  • ✓ Draw routes directly on the map using the interactive interface
  • ✓ Import existing route geometries from CAD/GIS files (GeoJSON)
  • ✓ Perform automated EMC compliance checks against RLN00398-V004 criteria
  • ✓ Compare multiple route alternatives side-by-side
  • ✓ Generate professional reports for Request for Proposal (RFP) documentation
  • ✓ Document design details: cable type, layout, earthing points, joint locations

Engineering Value:

  • ⚡ Early identification of EMC compliance issues during route planning
  • 📊 Optimize detailed study efficiency with well-documented preliminary analysis
  • 🤝 Facilitate collaboration between engineers, clients, and stakeholders
  • ✅ Clear overview of which routes pass/fail criteria and what's needed to meet requirements
  • 🛡️ Address ProRail safety concerns and permitting requirements upfront

How to Use This Tool:

1. Create or Import Routes

Click ➕ in the Routes panel to draw, or import GeoJSON files from CAD systems

2. Configure Route Details

Specify voltage level, cable type, installation method (underground/overhead)

3. Evaluate Compliance

Click 'Evaluate' to run automated checks against RLN00398 requirements

4. Review Results & Optimize

Analyze distance measurements, crossing angles, and compliance status

5. Generate Reports

Export professional documentation for RFP submissions or design records
